# Планировщик задач (Final Project)

Веб-сервер на языке Go для управления списком дел. Проект включает в себя API для создания, редактирования, удаления и получения задач, а также фронтенд-часть.

### Описание проекта
Сервер реализует логику планирования задач с поддержкой правил повторения. Данные хранятся в SQLite.

### Выполненные задания со звёздочкой:
* **Аутентификация**: Защита API с помощью JWT-токенов и пароля.
* **Поиск**: Фильтрация задач по тексту или дате.
* **Удаление**: Полноценный эндпоинт для удаления задач.

### Инструкция по запуску сервера:
1. Перейдите в папку проекта: `cd go_final_project`.
2. Установите пароль для доступа и запустите сервер (команда для PowerShell):
   ```powershell
   $env:TODO_PASSWORD="12345"; go run main.go
Сервер будет доступен по адресу: http://localhost:7540.

Инструкция по запуску тестов:
Убедитесь, что сервер запущен с паролем 12345.

В файле tests/settings.go должны быть установлены:

Port = 7540

Password = "12345" (если этот параметр есть в ваших тестах)

Выполните команду в терминале:
go test -v ./tests/...
